# mcp-learning

A project dedicated to exploring the Model Context Protocol (MCP).

## Prerequisites

- [Bun](https://bun.sh/) (latest version recommended)

## Installation

```bash
bun install
```

## Running the Project

```bash
bun run index.ts
```

## Structure

- `index.ts`: Main entry point.
- `src/client.ts`: MCP client implementation.
- `src/server.ts`: MCP server implementation.
